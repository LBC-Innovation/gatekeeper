# inbox

Drop exports here for the internal sensors: support tickets, returns, lost-deal notes,
downtime logs, an Azure DevOps work-item export. Any text format (CSV, markdown, plain text).

Scouts for `unexpected_occurrences`, `incongruities` and `process_needs` read only this folder
and cite files as `file:///<absolute path to the file>`. Nothing here is ever sent to a web search.
